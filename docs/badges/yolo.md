# YOLO

Merge a pull request **without a review** (where policy allows).

## On your own repo

1. Repo → **Settings** → **Branches** — relax or disable required reviews for `main` (temporarily).
2. Open a PR from a branch.
3. Merge without approval.

Restore branch protection afterward.

## Warning

Do not do this on org repos you do not control. One merge is enough for the default tier.
