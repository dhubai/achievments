# Starstruck

A repository **you created** gains stars. Tiers are usually tied to star count on that repo (not forks).

## Community-reported tiers (one repo)

| Tier | Stars |
|------|-------|
| Default | 16 |
| Bronze | 128 |
| Silver | 512 |
| Gold | 4096 |

GitHub does not publish these numbers; hover your badge for the real hint.

## How people actually earn it

- Ship something useful: CLI, template, docs, small library, dataset.
- README with clear install steps and a GIF or screenshot.
- Share where your audience already is (not star-exchange rings).

## Track progress

```bash
./scripts/progress.sh
```

Look at `starstruck_max_stars_on_owned_repo`.
