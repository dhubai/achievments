# Pull Shark

Merged pull requests **you opened** (count toward tiers).

## Community-reported tiers

| Tier | Merged PRs opened |
|------|-------------------|
| Default | 2 |
| Bronze | 16 |
| Silver | 128 |
| Gold | 1024 |

## Fastest honest path

1. Use this repo (or any real project) and open small, scoped PRs.
2. Prefer repos where you are a maintainer so reviews merge cleanly.
3. Run `./scripts/progress.sh` to see `pullRequests(states: MERGED).totalCount`.

## Avoid

- Empty or deceptive PRs across random repos (spam; may violate ToS).
- Merging your own PRs in someone else’s repo without maintainer consent.

## Check on GitHub

Profile → Achievements → **Pull Shark** (hover for the official hint).
