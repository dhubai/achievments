# Galaxy Brain

Have an answer **accepted** in a repository **Discussions** Q&A category.

## Community-reported tiers

| Tier | Accepted answers |
|------|------------------|
| Default | 2 |
| Bronze | 8 |
| Silver | 16 |
| Gold | 32 |

## Steps

1. Enable **Discussions** on a repo (yours or one you help maintain).
2. Use the **Q&A** category.
3. Ask a real question; answer with a solution; mark as accepted (or ask the asker to accept).

Quality matters more than volume — accepted answers must solve the question.
