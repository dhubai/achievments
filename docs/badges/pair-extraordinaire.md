# Pair Extraordinaire

[Co-authored commits](https://docs.github.com/en/pull-requests/committing-changes-to-your-project/creating-and-editing-commits/creating-a-commit-with-multiple-authors) on **merged** pull requests.

## Community-reported tiers

| Tier | Merged PRs with co-authored commits |
|------|-------------------------------------|
| Default | 1 |
| Bronze | 10 |
| Silver | 24 |
| Gold | 48 |

## How to co-author

In the commit message body:

```text
Co-authored-by: Name <email@example.com>
```

Both authors need to be on commits that land via a **merged** PR.

## Easiest path

Pair with a friend on this playbook repo: alternate small PRs with co-authored trailers.
