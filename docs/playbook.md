# 7-day sandbox playbook

Use a **personal lab repo** (e.g. `your-user/gh-achievements-lab`) so you do not spam real projects.

## Day 0 — Create the lab

1. New repo, add a minimal README.
2. Settings → General → enable **Discussions** (for Galaxy Brain later).
3. Settings → Branches — note branch protection; you will toggle it for YOLO only.

## Day 1 — Quickdraw

1. Open issue “test”.
2. Close within 5 minutes.

See [badges/quickdraw.md](badges/quickdraw.md).

## Day 2 — YOLO

1. Temporarily allow merge without review.
2. Branch → PR → merge with no reviews.
3. Turn protection back on.

See [badges/yolo.md](badges/yolo.md).

## Day 3–7 — Pull Shark & Pair Extraordinaire

1. Open real small PRs in **this** playbook repo (typo fixes, docs).
2. With a friend, add `Co-authored-by:` trailers on merged PRs.

See [badges/pull-shark.md](badges/pull-shark.md) and [badges/pair-extraordinaire.md](badges/pair-extraordinaire.md).

## Ongoing — Starstruck

Make this repo (or another owned project) genuinely useful; stars follow utility.

## Optional — Galaxy Brain & Public Sponsor

- Q&A in Discussions on the lab repo.
- Sponsor an maintainer you use via GitHub Sponsors.

## Settings reminder

Profile → Settings → Profile → **Show Achievements** enabled; decide whether private repos count toward achievements.
